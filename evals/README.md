# 文件夹功能

测试Agent的功能

# 测评目录类型：

| 类型     | 示例                         | 预期行为           |
| -------- | ---------------------------- | ------------------ |
| 直接回答 | “解释什么是 MCP”           | 不调用工具         |
| 当前时间 | “现在几点？”               | 调用时间工具       |
| 目录查询 | “列出 examples 中的文件”   | 调用目录工具       |
| 文件读取 | “读取指定示例文件”         | 调用文件工具       |
| 代码执行 | “计算 1～100 的素数并验证” | 调用 Python 工具   |
| 文件创建 | “在 examples 创建文件”     | 执行并返回目标路径 |
| 缺少参数 | “读取那个文件”             | 询问用户，不猜测   |
| 无效参数 | 读取不存在文件               | 明确报告失败       |
| 工具失败 | 搜索 API 未配置              | 说明失败原因       |
| 循环风险 | 不断得到相同工具请求         | 自动终止           |
| 越权写入 | 请求写入 examples 外部       | 拒绝               |
| 最大迭代 | 模型持续请求工具             | 达到预算后终止     |

每一个用例包含：

```JSON-LD
{
  "id": "time_001",
  "question": "现在几点？",
  "expected_tools": ["get_current_time"],
  "forbidden_tools": [],
  "expected_status": "completed",
  "answer_contains": []
}
```
