
测试分三层：

1. 工具单元测试
   不访问真实 LLM，重点验证工具本身：

- 正常文件读取。
- 文件不存在。
- 非 UTF-8 文件。
- 文件超过大小限制。
- 允许目录和禁止目录。
- 文件已存在时拒绝覆盖。
- Python 正常执行、报错和超时。

2. Agent 单元测试
   使用假的 LLM 和 MCP Manager，不请求真实 API。
   假的 LLM 应能按测试脚本依次返回：
   第一次：请求工具
   第二次：返回最终回答
   重点验证：

- 没有工具时直接结束。
- 单次工具调用。
- 一轮调用多个工具。
- 工具参数 JSON 非法。
- 工具执行失败。
- 模型反复调用相同工具。
- 超出运行上限。
- 对话记忆是否正确写入。

3. MCP 集成测试
   启动真实 MCP 子进程，但不调用外部网络服务，验证：

- MCP 能正常连接。
- 工具列表完整。
- 时间工具可以调用。
- 工具响应能被正确解析。
- 未知工具返回合理错误。
